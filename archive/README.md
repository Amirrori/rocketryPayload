pi-backups/ has the older copies of the code from /home/uhrkpay/backups on the pi. This is the website from 30/06/2026 and two versions of the gps changes from 02/07/2026.

SD_CARD_MANIFEST-20260630.txt is the file list and system info from when the SD card was exported on 30/06/2026 (the codex branch).

bash_history.txt is the command history of uhrkpay on the pi and shows how everything was set up. The laptop wifi password was replaced with <LAPTOP_WIFI_PASSWORD>.

The old readmes from the main and codex branches are in docs/old/.
